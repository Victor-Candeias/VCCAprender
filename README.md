# VCCAprender
🌟 VCC Aprender — Aprender, Brincar e Descobrir! 🎨 Aplicação educativa para crianças dos 3 aos 8 anos, com jogos interativos, letras, números, cores, formas, animais e sons. Inclui cartões mágicos com smiles surpresa, leitura em voz alta, desafios, recompensas e acompanhamento da evolução. 📚 100% offline e em português!

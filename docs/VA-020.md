# VA-020 — Importação e exportação JSON

## Funcionalidades
- Botões **Importar JSON** e **Exportar JSON** no editor de atividades.
- Android Storage Access Framework (OpenDocument/CreateDocument); sem permissão de armazenamento geral.
- Ficheiro JSON versionado: `format=vcc-aprender-cards`, `version=1`, `cards`.
- Cada cartão inclui `topic`, `difficulty`, `question`, `options` (três textos) e `correctIndex` (0, 1 ou 2).
- IDs locais Room não são exportados; cartões importados recebem novos IDs.
- Validação integral antes da gravação; limite de 1 MiB e 500 cartões por ficheiro.
- Duplicados exatos (mesmo tema, dificuldade, pergunta, respostas e índice correto) são ignorados.
- Importação agrupada numa transação Room; dados anteriores são mantidos.
- Leitura e escrita fora da thread principal; feedback de sucesso/erro.
- Testes instrumentados de serialização, versão inválida, tema inválido e respostas duplicadas.

## Exemplo
```json
{
  "format": "vcc-aprender-cards",
  "version": 1,
  "cards": [
    {
      "topic": "ANIMALS",
      "difficulty": "EASY",
      "question": "Que animal faz miau?",
      "options": ["Cão", "Gato", "Vaca"],
      "correctIndex": 1
    }
  ]
}
```

## Limitações
A exportação inclui somente cartões personalizados, não perfis, resultados nem catálogo integrado. Não existe ainda partilha automática ou sincronização na nuvem. Os testes e a compilação ainda não foram executados neste ambiente.

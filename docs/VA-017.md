# VA-017 — Testes de interface e navegação

## Testes instrumentados adicionados
- `HomeScreenUiTest`: lista de temas, seleção e recuperação de erro.
- `ProfileScreenUiTest`: abertura/cancelamento de criação de perfil e confirmação de erro.
- `ParentalSettingsUiTest`: visualização de preferências e botão de voltar.
- `ProgressScreenUiTest`: estado vazio, resumo e botão de voltar.

Estes testes validam callbacks e transições locais dos ecrãs. **Não cobrem ainda a navegação end-to-end pelo NavHost**, a persistência real do Room/DataStore ou os fluxos de criação de perfil com base de dados.

## Executar
Requer emulador Android iniciado ou dispositivo ligado:
```bash
adb devices
./gradlew :app:connectedDebugAndroidTest --no-daemon --max-workers=1 --no-parallel
```
Compilação dos testes instrumentados sem dispositivo:
```bash
./gradlew :app:assembleDebugAndroidTest --no-daemon --max-workers=1
```

## Validação manual complementar
- Criar perfil, entrar, abrir um tema e voltar.
- Abrir área parental, alterar preferências, reiniciar app e confirmar persistência.
- Registar respostas e confirmar evolução por tema.
- Testar orientação, tamanhos de ecrã, TalkBack e modo avião.

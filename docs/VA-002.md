# VA-002 — Arquitetura MVVM e estrutura modular

## Organização
- `ui/home`: Compose e estado de apresentação; ViewModel expõe StateFlow.
- `domain/model`: conceitos do negócio independentes do Android.
- `domain/repository`: contratos de acesso a dados.
- `domain/usecase`: casos de utilização.
- `data/repository`: implementação offline.
- `di`: composição manual de dependências sem framework DI.

O projeto permanece com um módulo Gradle `app` e pacotes separados por responsabilidade. A divisão em módulos Gradle físicos pode ser feita quando o código justificar a complexidade adicional.

## Fluxo
`MainActivity -> HomeScreen -> HomeViewModel -> GetLearningTopicsUseCase -> LearningRepository -> OfflineLearningRepository`

A UI recebe um estado imutável `Loading`, `Success` ou `Error`. A fonte de dados é local e não requer permissões de Internet. Room e DataStore ficam reservados para funcionalidades que exijam persistência.

## Verificação
Executar `./gradlew :app:assembleDebug :app:testDebugUnitTest` num ambiente Android com wrapper configurado. Validar arranque, rotação, acessibilidade e modo avião num emulador. O build e os testes ainda não foram executados neste trabalho.

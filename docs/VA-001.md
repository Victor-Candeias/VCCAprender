# VA-001 — Fundação Android

Projeto inicial Android com Kotlin, Jetpack Compose, Material 3 e dependências para MVVM e navegação.

## Requisitos
- JDK 17
- Android SDK 35
- Gradle 8.9 (compatível com Android Gradle Plugin 8.7.3)

## Build
Abrir a raiz no Android Studio e sincronizar o Gradle. Para compilação por terminal, instalar Gradle 8.9 ou adicionar o Gradle Wrapper:

```bash
gradle wrapper --gradle-version 8.9
./gradlew :app:assembleDebug
./gradlew :app:testDebugUnitTest
```

O wrapper ainda não está incluído. O primeiro comando requer Gradle instalado.

## Estrutura
- `app/src/main/java`: interface Compose; módulos futuros devem separar `ui/`, `domain/` e `data/`.
- `app/src/main/res`: recursos em português.
- `app/src/main/AndroidManifest.xml`: entrada da aplicação sem permissões de rede.
